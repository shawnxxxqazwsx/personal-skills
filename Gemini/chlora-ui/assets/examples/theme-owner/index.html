为什么会拖尾

继承的 color 会随祖先动画每帧变化。子元素再对这个不断移动的目标做一次过渡，就没有共同的固定终点。每层都写 320ms，也可能直到 320ms 之后仍在追逐中间色。

生产 owner 先捕获当前画面；切换主题后，先读取所有元素的目标色，再为每个元素建立固定起止色的 WAAPI keyframes。快速反向时先采样当前画面，再取消旧动画。材料仍交给原主题 CSS 规则，前景不靠多层继承过渡。

右侧没有补写 dark-palette-only 的新动画、没有改生产算法。Normal / Reduced 是隔离 iframe 中针对唯一 media query 的演习适配；不会修改操作系统偏好。切换该模式会先将当前主题立即收尾，然后供下一次切换使用。
